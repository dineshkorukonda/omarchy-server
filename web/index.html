Architecture Invariants

Design decisions that prioritize operational resilience

01 / TRANSPORT

Erlang Native :ssh Engine

Eliminates reliance on external ssh binaries or OpenSSH-for-Windows installations. Executes via OTP :ssh_connection directly in runtime memory.

02 / CREDENTIALS

OS Credential Stores

Secrets never touch local config files. Integrates with Windows Credential Manager and Linux Secret Service (libsecret) with ephemeral in-memory passphrase caching.

03 / RESOURCE EFFICIENCY

Focus-Aware Polling

Background hosts dynamically throttle telemetry checks to backoff intervals. Non-interactive exec channels are used for metrics rather than holding open idle PTY shells.
