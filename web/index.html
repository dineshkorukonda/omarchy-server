Desktop Client / v0.0.1 (pre-release)

Cross-platform desktop SSH client and infrastructure monitor.

Built on Erlang/OTP with direct native transport, OS keychain integration, xterm.js terminal, and live server telemetry. Offline-first, zero telemetry, no external accounts.

Credentials never touch plain config files. Passwords and keys resolve through OS Credential Manager (Windows) or libsecret (Linux) at connect time.

Architecture & Technical Spec

Design invariants and system boundaries

Stack

  • Runtime Erlang/OTP 27 + Elixir 1.18
  • Transport Native :ssh app (:ssh_connection)
  • Terminal xterm.js via Phoenix Channels
  • Desktop Shell elixir-desktop (WebView2 / WebKitGTK)
  • Keychain Credential Manager / libsecret
  • Packaging mix release (self-contained OTP)

Invariants

No external ssh binary: Erlang OTP handles transport natively on all OS targets.

Resource discipline: Backgrounded hosts back off polling; interactive shells open only when focused.

Plain errors: Auth rejects, timeouts, network unreachability, and fingerprint diffs map to explicit diagnostics.

Zero telemetry: Completely functional in air-gapped networks. Zero external pings.

Changelog

Full commit history and release specifications

v0.0.1
v0.0.1 — Initial pre-release package
2026-09-05 • release notes ↗

Added

  • • Native Erlang/OTP SSH Transport: Replaced external shell commands with direct :ssh, :ssh_connection, and :ssh_sftp modules.
  • • Authentication System: Implemented SSHClient.SSH.Auth callback module supporting key-based (ed25519, rsa, custom paths), password, ssh-agent, and keyboard-interactive auth with per-host priority order.
  • • Host Key Verification: Added HostKeyVerifier with visual fingerprint diffing on changed host keys and strict reject-by-default logic.
  • • Terminal Bridge: Embedded xterm.js container bridged over Phoenix Channel (TerminalChannel) to OTP PTYSession with PTY resize and bracketed paste support.
  • • Desktop Window: Bootstrapped elixir-desktop native shell (SSHClient.Window) backed by WebView2 on Windows and WebKitGTK on Linux.
  • • Host Management: Added user@host:port quick parser, automatic ~/.ssh/config importer, and fuzzy search with ranking across flat host lists.
  • • OS Keychains: Implemented Windows Credential Manager and Linux Secret Service (libsecret) backends with ephemeral in-memory passphrase cache.
  • • Operations & Telemetry: Focus-aware CPU/RAM/disk metrics polling with background backoff, systemd/Docker/PM2 remote action panel, and journalctl log viewer.
  • • Terminal UI (TUI): Portable ssh-client-tui CLI script audited and adapted for Windows Terminal and Linux consoles.
  • • Packaging & Releases: GitHub Actions matrix CI (Windows & Ubuntu runners, Docker OpenSSH tests), automated mix release packaging, and tag-triggered release distribution.

Fixed & Changed

  • • Fixed Windows socket fallback to prevent crash on non-Unix domain socket operating systems.
  • • Fixed host key verification callback to safely accept character list hostnames from Erlang :ssh.
  • • Removed UTF-8 BOM encoding across all repository files for strict compiler compliance.
  • • Refined 2-character query boundary matching in fuzzy search engine.
  • • Migrated app name from omarchy-server to ssh-client (SSHClient.* namespace) and removed all QML desktop bar dependencies.

Prior History: omarchy-server (v0.1.0)

Historical releases originated as omarchy-server, an agentless SSH monitoring daemon and QML bar widget for Omarchy/Hyprland on Linux. Included Unix socket JSON API, init-system inspection, and PTY terminal daemon.

Installation

Download prebuilt standalone bundles or build from source

Windows (PowerShell)

Invoke-WebRequest -Uri https://github.com/dineshkorukonda/ssh-client/releases/download/v0.0.1/ssh-client-windows-x64.zip -OutFile ssh-client.zip

Expand-Archive -Path ssh-client.zip -DestinationPath "C:\Program Files\ssh-client"

& "C:\Program Files\ssh-client\bin\ssh_client.bat" start

Linux (Bash)

curl -sSL -O https://github.com/dineshkorukonda/ssh-client/releases/download/v0.0.1/ssh-client-linux-x64.tar.gz

tar -xzf ssh-client-linux-x64.tar.gz -C /opt/ssh-client

/opt/ssh-client/bin/ssh_client start

Build from Source (Elixir 1.18+ / OTP 27+)

git clone https://github.com/dineshkorukonda/ssh-client.git

cd ssh-client && mix deps.get

iex -S mix
