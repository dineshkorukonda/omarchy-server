Philosophy & Architecture

Built to avoid modern terminal client failure modes

No cloud accounts. No forced subscriptions. No telemetry beacons. No silent connection dropouts.

🔒

100% Offline & Private

Never requires an account or internet connectivity to function. Your server list and credentials never leave your physical device. Zero telemetry or tracking calls.

🛡️

OS-Native Keychains

Credentials are never stored in plaintext config files. Directly integrates with Windows Credential Manager and Linux Secret Service (libsecret).

⚡

Native Erlang :ssh Engine

Does not rely on shelling out to external ssh binaries. Full support for Key, Password, Agent, and Keyboard-Interactive auth on all platforms.

Core Capabilities

Engineered for infrastructure operators

💻

Integrated xterm.js Terminal

Full PTY support with terminal resize detection, bracketed paste mode, 256-color support, and bidirectional streaming over Phoenix Channels to OTP shell sessions.

📊

Live Resource Discipline

Lightweight GenServer per host polls CPU, RAM, disk, and load average over non-interactive exec channels. Automatic backoff when hosts are in the background.

⚙️

Remote Service & Container Control

Inspect, restart, or stop systemd units, Docker containers, and PM2 processes with one click and safety confirmations.

📜

Remote Log Streaming

Tail journalctl and system logs directly inside the UI without opening full interactive terminal sessions.

🔍

Fuzzy Search & ~/.ssh/config Import

One-click import of your existing OpenSSH configuration with duplicate prevention. Instant fuzzy searching across hundreds of hosts, addresses, and tags.

🔑

Strict Host-Key Verification

Full fingerprint visual diffing on changed host keys with explicit accept/reject flow. Reject-by-default on mismatches prevents silent MITM vulnerabilities.

Get Started

Installation

Run natively as a desktop app or standalone terminal daemon.

🪟

Windows (PowerShell)

Download and extract the prebuilt Windows x64 release package:

Invoke-WebRequest -Uri https://github.com/dineshkorukonda/ssh-client/releases/latest/download/ssh-client-windows-x64.zip -OutFile ssh-client.zip
Expand-Archive -Path ssh-client.zip -DestinationPath "C:\Program Files\ssh-client"
& "C:\Program Files\ssh-client\bin\ssh_client.bat" start
🐧

Linux (Bash / Curl)

Extract the self-contained OTP release archive:

curl -sSL -O https://github.com/dineshkorukonda/ssh-client/releases/latest/download/ssh-client-linux-x64.tar.gz
tar -xzf ssh-client-linux-x64.tar.gz -C /opt/ssh-client
/opt/ssh-client/bin/ssh_client start
🛠️

Build from Source (Elixir & OTP)

Requires Elixir 1.15+ and Erlang/OTP 26+:

git clone https://github.com/dineshkorukonda/ssh-client.git && cd ssh-client
mix deps.get
# Run interactive development shell + desktop window:
iex -S mix
# Or build a standalone self-contained release:
MIX_ENV=prod mix release
